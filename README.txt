SPORT TRAINING — стартовая версия Mini App

Содержимое:
- index.html — разметка приложения
- style.css — оформление
- app.js — взаимодействия и локальное сохранение результатов

Быстрый просмотр:
1. Откройте папку в Visual Studio Code.
2. Откройте index.html в браузере (удобно через расширение Live Server).
3. Для проверки можно открыть страницу на компьютере или телефоне.

Подключение к Telegram:
1. Разместите эти три файла на HTTPS-хостинге.
2. В BotFather откройте настройки бота и настройте Menu Button / Web App URL
   (названия пунктов могут немного отличаться).
3. Укажите HTTPS-адрес index.html.
4. Откройте бота и нажмите кнопку Mini App.

Важно:
- Это первая фронтенд-версия. Результаты и отметки пока сохраняются локально
  в браузере, а не в общей базе данных.
- Для синхронизации между устройствами следующим этапом подключим Python/aiogram
  и SQLite, а затем будем проверять Telegram initData на сервере.
- Не вставляйте токен Telegram-бота в HTML, CSS или JavaScript.
- Программа демонстрационная и не заменяет индивидуальный план тренера.
